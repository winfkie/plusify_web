PLUSIFY - Website v2
BUKA: index.html (klik 2x atau pakai Live Server)

YANG WAJIB KAMU ISI (js/config.js):
1. ADMIN_WA   -> nomor WhatsApp admin (format 628xxxxxxxxxx)
2. QRIS       -> simpan gambar QRIS di assets/qris.jpeg
3. EWALLETS   -> nomor & atas nama DANA / GoPay / OVO / ShopeePay (hapus yang tidak dipakai)
4. Logo Plusify -> assets/logo.png

LOGO PRODUK:
- 18 logo sudah tertanam langsung (tanpa internet).
- Sisanya otomatis ambil dari domain resmi aplikasinya. Kalau mau logo sendiri, simpan di
  assets/logos/<nama>.png, contoh: assets/logos/capcut.png, assets/logos/disney.png, assets/logos/wetv.png
  (nama file = nama produk huruf kecil, spasi/simbol jadi tanda -). Kalau gagal semua, tampil inisial berwarna.

ALUR CHECKOUT: Produk -> varian (paket sharing/private + durasi) -> Keranjang -> Data diri + metode (QRIS / E-Wallet)
-> Halaman bayar (QRIS atau nomor e-wallet) -> klik "Saya Sudah Bayar" -> WhatsApp admin terbuka dengan template pesanan.
